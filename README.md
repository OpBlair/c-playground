# C Programming Playground

> A personal sandbox for revisiting C fundamentals, sharpening problem-solving skills, and building small command-line programs from scratch.

Getting my hands dirty with C again, diving back into the waters, and rebuilding my programming muscle memory one small project at a time.

---

## What's Inside?

A collection of small projects and experiments covering different aspects of C programming, starting with the basics and gradually moving into more advanced concepts.

### Learning Roadmap
* **Fundamentals:** Variables, data types, operators, conditionals, loops, and functions.
* **Arrays & Strings:** Working with arrays, character manipulation, and string handling.
* **Pointers:** Understanding memory addresses, pointer arithmetic, and passing by reference.
* **Structures:** Organizing data using custom `struct` types.
* **File Handling:** Reading from and writing to files.
* **Problem Solving:** Small challenges and exercises to strengthen logical thinking.

## Getting Started

You'll need a C compiler installed. I use **GCC** for compilation.

### 1. Clone the Repository
```bash
git clone [https://github.com/OpBlair/c-playground.git](https://github.com/OpBlair/c-playground.git)
cd c-playground

```

### 2. Compile a Program

```bash
gcc -Wall -Wextra filename.c -o app

```

### 3. Run It

```bash
./app

```

## Philosophy

* **Keep it small:** Focus on one concept per project.
* **Understand deeply:** Prioritize conceptual clarity over just getting code to compile.
* **Embrace the bugs:** Experiment, make mistakes, debug, and learn.
* **Iterate:** Gradually increase complexity as fundamentals become second nature.
